# 股票盯盘 AI 助手 — 项目说明

## 一、项目概述

这是一个带 LCD/TFT 彩屏的股票盯盘设备。

硬件平台：**ESP32**，固件使用 **ESP-IDF (C/C++)** 开发。

设备可以连接网络，并通过一个网页管理界面进行配置（网页服务直接运行在设备上）。

用户可以在网页中配置股票数据接口，并根据接口返回的数据选择自己需要显示的信息，最终将这些信息按照自己的需求布局到设备屏幕上。

项目的核心理念：

> **用户提供数据接口 → 系统自动解析数据 → 用户选择需要的数据 → 用户布局屏幕显示 → 设备自动获取并显示**

---

# 二、项目组成

项目主要由两个部分组成：

```text
股票盯盘设备（ESP32 + LCD/TFT 彩屏）
      │
      ├── 屏幕显示
      ├── 网络连接
      ├── 数据获取
      └── 数据显示

设备管理网页（运行在设备上）
      │
      ├── 设备设置
      ├── 接口配置
      ├── 数据字段解析
      ├── 屏幕显示配置
      └── 配置保存
```

网页管理功能直接运行在设备上。

项目第一阶段不需要独立的服务器后台。

## 技术栈约定

```text
固件/后端：ESP-IDF (C/C++)
屏幕：LCD/TFT 彩屏
接口格式：HTTP，JSON 为主（支持对象/数组），后续可兼顾其他格式
字段解析：设备端通用 JSON 自动解析，不实现 AI
配置存储：设备本地（NVS / Flash 文件），重启后复用
```

# 四、设备端

设备是整个项目的最终运行载体，基于 ESP32 + ESP-IDF。

主要负责：

```text
网络连接
    ↓
获取股票数据
    ↓
解析数据（JSON 自动解析）
    ↓
根据用户配置提取数据
    ↓
格式化（颜色/百分号/小数位/单位）
    ↓
显示到屏幕
```

设备还需要保存用户的配置（NVS / Flash）。

设备重新启动后，应能够继续使用之前保存的配置。

---

# 五、网页管理界面

网页主要用于配置设备，运行在设备上，通过局域网访问。

大致分为以下几个部分：

## 1. 设备设置

用于查看和配置设备本身的信息。

例如：

```text
设备名称
网络（AP 配网 / 局域网）
屏幕相关设置（亮度、刷新频率）
其他设备设置
```

## 2. 接口配置

用户输入股票数据接口地址（由外部系统提供的 HTTP 接口）。

例如：

```text
接口地址：
[                         ]

        [测试接口]
```

测试成功后，显示接口返回的数据。

## 3. 数据字段解析

系统对接口返回的 JSON 数据进行**通用自动解析**（递归展开对象/数组，生成字段树）。

例如接口返回：

```text
{
  "code": "000001",
  "name": "平安银行",
  "price": 12.34,
  "changePercent": 1.23,
  "volume": 12345678
}
```

系统将这些数据整理成可以选择的字段：

```text
股票代码
股票名称
当前价格
涨跌幅
成交量
```

用户可以选择：

```text
股票名称
当前价格
涨跌幅
成交量
```

# 六、屏幕显示配置

用户选择需要显示的数据之后，可以在网页上用**拖拽/网格布局**的方式，将这些数据自由摆放到屏幕上的任意位置。

例如：

```text
┌──────────────────────┐
│  平安银行    +1.23%   │
│     12.34  (红涨)     │
│                      │
│  成交量  12345678     │
└──────────────────────┘
```

用户可以调整：

```text
显示哪些内容
内容显示的位置（拖拽/网格摆放）
内容显示的大小
内容的排列方式
字段的显示格式（颜色/百分号/小数位/单位）
```

支持**多只股票**：一个接口可返回多只股票，用户可按需把多只股票分别布局到屏幕上（同屏列表、任意位置均可，由用户自行布局）。

最终形成一个屏幕显示方案。

# 十、AI 功能（外部数据源定位）

**AI 不作为设备端的功能实现。**

股票数据接口由**外部 AI 系统（或其他数据服务）**提供，返回结构化的 JSON 数据（对象/数组）。

设备端的职责：

```text
外部 AI 系统提供接口
       ↓
设备获取接口数据
       ↓
通用 JSON 自动解析（对象/数组展开）
       ↓
用户识别并选择字段
       ↓
配置显示格式
```

AI 辅助能力（如字段含义解释、自动识别"当前价格/涨跌幅"等）属于网页端的可选辅助功能，后续按需逐步增加，不阻塞第一阶段闭环。

第一阶段只需要完成一个完整的基本闭环：

```text

   ↓

   ↓
获取接口数据
   ↓
自动解析字段
   ↓

   ↓

   ↓

   ↓
保存
   ↓

   ↓
屏幕显示
```

第一阶段范围：


先确保这个流程完整运行。

其他高级功能（多接口、更多数据格式、AI 辅助解释等）在基础流程完成后再逐步增加。
